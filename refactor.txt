2. PRIORITAS TINGGI - PERKUAT ARCHITECTURE RULE

2.1. Sesuaikan pesan rule dengan factory aktual
- File:
  src/test/java/org/example/ArchitectureTest.java
- Masalah:
  Komentar/contoh menyebut pages.manageOrganization().getDashboardPage(), tetapi factory aktual belum punya manageOrganization().
- Target:
  Setelah factory chain dibuat, update contoh agar sesuai nama method final.

2.2. Tambah rule untuk Back Office test
- File:
  src/test/java/org/example/ArchitectureTest.java
- Target:
  Test class Back Office juga tidak boleh instantiate PageObject langsung.
- Rule:
  noClasses()
      .that().resideInAPackage("org.example.test.backoffice..")
      .should().callConstructorWhere(target package startsWith "org.example.pageObject.backoffice")

2.3. Pertimbangkan rule untuk semua package test
- Target:
  Package test tidak boleh instantiate PageObject dari src/main/pageObject secara langsung.
- Catatan:
  Exception mungkin dibutuhkan untuk utility legacy seperti TableUtils/ActionUtils jika belum direfactor.
  Jangan aktifkan rule terlalu luas sebelum utility tersebut dirapikan.

2.4. Tambah rule factory-only constructor access
- Target jangka menengah:
  Constructor PageObject hanya boleh dipanggil dari package factory.
- Rule konsep:
  Classes outside org.example.factories.. should not call constructors of org.example.pageObject..
- Catatan:
  Perlu whitelist untuk PageObject internal/component jika ada komposisi yang valid.
- Catatan tambahan:
  Jangan langsung blok semua constructor di package org.example.pageObject.. tanpa klasifikasi.
  Component kecil seperti SlaRowComponent saat ini di-instantiate di TableUtils dan lebih cocok diperlakukan sebagai component object/internal row wrapper, bukan full PageObject.
  Sebelum rule factory-only diaktifkan penuh, tentukan salah satu pendekatan:
  - Daftarkan component internal melalui factory khusus, atau
  - Pindahkan component ke package ..components.. dan whitelist package tersebut di ArchitectureTest, atau
  - Biarkan component di-instantiate oleh PageObject induk saja, lalu hilangkan pemanggilan dari util.
