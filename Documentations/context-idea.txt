You are an automation engineer. Implement a Selenium-based test framework optimization with the following requirements:

GOAL:
Reduce test execution time by avoiding repeated login and repeated slow page load on staging environment.

CONTEXT:

* The staging website is very slow (initial page load can take 2–5 minutes).

* We want to minimize how many times the browser loads the initial URL.

1. SINGLE BROWSER SESSION

* Do NOT close or quit the browser between test cases.
* Only close the browser after all tests are finished.

2. LOGIN ONLY ONCE

* Perform login only in the initial setup phase.
* After login is successful, reuse the same browser session for all subsequent tests.
* Do NOT repeat login in each test.

3. SESSION REUSE

* Ensure that authentication state (cookies, localStorage, etc.) is preserved automatically by keeping the browser alive.
* Do NOT clear cookies unless explicitly required.

4. TEST STRUCTURE

* Separate setup, test execution, and teardown clearly.

  * Setup: open browser → load URL → login
  * Tests: reuse the logged-in state
  * Teardown: close browser

5. SAFETY CHECK

* Before each test, verify that the user is still logged in.
* If redirected to login page, perform re-login automatically.

6. MINIMIZE driver.get CALLS

* Avoid calling driver.get(base_url) in every test.
* Navigate only when necessary.
* Prefer continuing from current page state.

  * setup method / fixture

* Focus on performance optimization for slow environments
